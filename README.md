# Fullstack .NET Journey

Exercises and projects from a 100-day **.NET Fullstack Developer** program at
[Lexicon](https://www.lexicon.se/) (autumn 2026).

With a background in backend development and testing in C#/.NET, I'm using this
program to extend my skills into full end-to-end development: from database and
API to frontend.
